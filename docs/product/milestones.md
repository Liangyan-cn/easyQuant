## 1. 产品愿景

**让个人投资者拥有专业级的量化投资能力**

easyQuant 致力于打破量化投资的技术壁垒，为个人投资者提供一站式的量化投资管理平台。

### 1.1 核心价值

### 1.2 差异化定位

| 差异点           | 竞品现状 | easyQuant 方案       | 用户价值                 |
| ---------------- | -------- | -------------------- | ------------------------ |
| **沙盒验证**     | 无       | 虚拟资金实时运行策略 | 降低实盘风险             |
| **本地可控**     | 云端为主 | 数据和策略本地存储   | 隐私安全                 |
| **回测实盘一致** | 部分支持 | 事件驱动统一框架     | 避免"回测天堂，实盘地狱" |
| **低门槛高上限** | 二选一   | 可视化 + Python 扩展 | 适合不同用户             |

### 10.2 术语表

| 术语                             | 定义                           |
| -------------------------------- | ------------------------------ |
| **因子 (Factor)**                | 用于预测股票收益的量化指标     |
| **IC (Information Coefficient)** | 因子值与未来收益的相关系数     |
| **IR (Information Ratio)**       | IC 均值 / IC 标准差            |
| **沙盒 (Sandbox)**               | 使用虚拟资金模拟真实交易的环境 |
| **回测 (Backtest)**              | 使用历史数据验证策略有效性     |
| **夏普比率 (Sharpe Ratio)**      | 超额收益 / 收益标准差          |
| **最大回撤 (Max Drawdown)**      | 净值从最高点到最低点的最大跌幅 |
