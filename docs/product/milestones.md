# Milestones

## 愿景 (Vision)

**让个人投资者拥有专业级的量化投资能力**

easyQuant 致力于为个人投资者打造一个**一站式量化投资管理平台**，帮助用户：
- **管理因子**：构建、测试和优化投资因子
- **管理策略**：设计、回测和部署量化策略
- **沙盒测试**：在安全环境中多策略实测评估
- **管理交易**：执行交易、监控持仓和风险

---

### M1.0 MVP - 核心基础功能

**目标**：完成系统基础框架，支持因子和策略的基本管理

- [ ] 用户认证系统（注册、登录、权限管理）
- [ ] 因子管理模块
  - 因子创建、编辑、删除
  - 因子回测能力
  - 因子组合与优化
- [ ] 策略管理模块
  - 策略创建、编辑、删除
  - 策略回测框架
  - 策略绩效评估
- [ ] 基础数据接口（股票、基金数据）

**交付价值**：用户可以创建自己的因子和策略，并进行基础回测

  - 绩效归因分析

## 远景规划 (Roadmap)

### 生态完善 (后续版本)

- 因子/策略市场（因子库共享、策略模板）
- 社区功能（用户交流、策略分享）
- 高级数据服务（另类数据、高频数据）
- 多终端支持（Web、移动端、桌面端）

### 企业级功能 (后续版本)

- 团队协作（多用户协同、权限管理）
- 合规与审计（交易合规、操作日志）
- 高级风控（全账户风控、压力测试）
- API 开放平台（第三方接入）
