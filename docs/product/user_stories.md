## 1. 用户故事概览

本文档定义 easyQuant 的核心用户故事，按用户角色和功能模块组织，每个故事包含：
- **角色 (As a)**：用户类型
- **场景 (When)**：触发场景
- **行为 (I want to)**：期望操作
- **价值 (So that)**：获得收益
- **验收标准 (Acceptance Criteria)**：可衡量的完成条件

## 2. 因子研究员故事

### US-F01：创建自定义因子

| 维度     | 描述                                                                  |
| -------- | --------------------------------------------------------------------- |
| **角色** | 进阶投资者（李华）                                                    |
| **场景** | 我发现低 PE + 高 ROE 的股票历史表现不错，想把这个逻辑变成可量化的因子 |
| **行为** | 我想创建一个自定义因子，定义计算公式，并给它命名                      |
| **价值** | 这样我可以在多只股票上批量计算这个指标，不用每次手动查数据            |

**验收标准**:
- [ ] 用户可以输入因子名称（1-100 字符）
- [ ] 用户可以选择因子分类（价值/成长/动量/波动率/质量/规模/流动性/技术/自定义）
- [ ] 用户可以输入因子计算公式（支持 Python 语法）
- [ ] 用户可以设置因子参数（如回看周期）
- [ ] 系统校验公式语法，错误时提示具体位置
- [ ] 创建成功后，因子出现在"我的因子"列表中
- [ ] 响应时间 < 500ms

**示例场景**:
```
用户操作：
1. 点击"新建因子"
2. 输入名称："价值成长复合因子"
3. 选择分类："价值"
4. 输入公式：
   pe_ratio = close / eps
   roe = net_profit / equity
   score = -pe_ratio * 0.5 + roe * 0.5
   return score
5. 点击"保存"

系统响应：
- 显示"因子创建成功"
- 跳转到因子详情页
- 因子状态为"草稿"
```

## 8. 验收标准汇总

### M1.0 MVP 验收标准

- [ ] 用户可以创建、编辑、删除因子
- [ ] 用户可以计算因子值（沪深300，1年数据，< 30s）
- [ ] 用户可以查看因子评估报告（IC、分组收益）
- [ ] 用户可以创建、编辑、删除策略
- [ ] 用户可以运行回测（5年数据，< 60s）
- [ ] 用户可以查看回测报告（收益曲线、绩效指标）
- [ ] 用户可以对比多个策略
- [ ] 系统提供至少 5 个示例策略
- [ ] 新用户可以在 10 分钟内完成首次回测

### M2.0 沙盒验收标准

- [ ] 用户可以创建沙盒账户
- [ ] 用户可以将策略部署到沙盒
- [ ] 系统每日自动执行沙盒策略
- [ ] 用户可以查看沙盒账户净值和持仓
- [ ] 用户可以对比多个沙盒策略
- [ ] 沙盒运行 30 天无重大 Bug

### M3.0 交易验收标准

- [ ] 用户可以查看实时持仓
- [ ] 用户可以手动下单（模拟）
- [ ] 用户可以查看交易记录
- [ ] 系统支持券商 API 对接（至少 1 家）
- [ ] 订单执行延迟 < 1s
