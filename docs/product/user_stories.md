# 核心用户故事

**项目**: easyQuant  
**版本**: v1.0  
**日期**: 2026-02-23

## 1. 因子研究员

### 1.1 用户画像
- 具备一定金融背景，关注因子有效性
- 需要快速验证因子的历史表现

### 1.2 用户故事
- 作为因子研究员，我希望能创建并管理因子，便于持续迭代优化
- 作为因子研究员，我希望能对因子进行历史回测，判断稳定性
- 作为因子研究员，我希望能查看核心绩效指标，评估因子质量

### 1.3 关键需求
- 因子创建、编辑、删除
- 因子回测与绩效评估
- 因子结果可视化与可解释性

## 2. 策略开发者

### 2.1 用户画像
- 具备编程或策略开发能力
- 关注策略逻辑正确性与收益稳定性

### 2.2 用户故事
- 作为策略开发者，我希望能创建策略并复用因子，提升开发效率
- 作为策略开发者，我希望能进行策略回测，评估收益与回撤
- 作为策略开发者，我希望能做参数敏感性分析，优化策略表现

### 2.3 关键需求
- 策略创建、编辑、删除
- 策略回测框架与参数测试
- 绩效指标与对比分析

## 3. 交易执行者

### 3.1 用户画像
- 关注交易执行与风险控制
- 需要清晰的策略信号与执行反馈

### 3.2 用户故事
- 作为交易执行者，我希望能在沙盒中验证策略，降低实盘风险
- 作为交易执行者，我希望能监控持仓与风险指标，及时调整仓位
- 作为交易执行者，我希望能查看交易记录，复盘执行效果

### 3.3 关键需求
- 沙盒环境与模拟交易
- 持仓管理与风险监控
- 交易记录与复盘分析

## 4. 与里程碑的关系

- **M0**：用户故事为产品定位与后续文档提供基础  
- **M1.0**：覆盖因子与策略管理的核心能力  
- **M2.0**：支持沙盒验证与多策略评估  
- **M3.0**：引导交易执行与风险管理能力
