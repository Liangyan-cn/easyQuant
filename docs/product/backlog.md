# Product Backlog

## 愿景 (Vision)

**让个人投资者拥有专业级的量化投资能力**

easyQuant 致力于为个人投资者打造一个**一站式量化投资管理平台**，帮助用户：
- 管理因子：构建、测试和优化投资因子
- 管理策略：设计、回测和部署量化策略
- 沙盒测试：在安全环境中多策略实测评估
- 管理交易：执行交易、监控持仓和风险

---

## 产品目标 (Product Goals)

1. **降低量化投资门槛**：让不懂编程的用户也能使用量化工具
2. **沙盒验证优先**：策略必须经沙盒实测验证后再实盘
3. **一站式管理**：集成因子、策略、沙盒、交易全流程
4. **数据驱动**：提供丰富的市场数据和回测分析
5. **安全可靠**：保障用户资金和交易安全

#### 股票池管理 详细需求

**功能描述：**
- 创建和管理自定义股票池
- 系统预置两个默认股票池：沪深300、中证500
- 支持从指数成分股批量导入
- 支持手动添加/删除股票

**数据模型：**
```
StockPool:
  - id: int
  - name: str (股票池名称)
  - description: str (描述)
  - is_system: bool (是否系统预置)
  - user_id: int (创建者，系统预置为 null)
  - created_at: datetime
  - updated_at: datetime

StockPoolItem:
  - pool_id: int
  - stock_code: str
  - added_at: datetime
```

**API 设计：**
- GET /api/v1/stock-pools - 获取股票池列表
- POST /api/v1/stock-pools - 创建股票池
- GET /api/v1/stock-pools/{id} - 获取股票池详情
- PUT /api/v1/stock-pools/{id} - 更新股票池
- DELETE /api/v1/stock-pools/{id} - 删除股票池
- POST /api/v1/stock-pools/{id}/stocks - 添加股票到池
- DELETE /api/v1/stock-pools/{id}/stocks/{code} - 从池中移除股票
- POST /api/v1/stock-pools/{id}/import-index - 从指数导入成分股

#### 数据缓存方案 详细需求

**设计目标：**
- 股票池内股票数据启动时预加载到内存
- 历史数据只获取一次，后续增量更新
- 支持定时自动更新（每日收盘后）

**数据量评估（沪深300+中证500）：**
- 股票数量：~800 只
- 日线历史 (5年)：~100 MB
- 财务报表：~64 MB
- 估值指标：~50 MB
- **总计：~250 MB（内存可承载）**

**缓存架构：**
```
┌─────────────────────────────────────┐
│  内存缓存 (启动时加载)              │
│  - 股票池成分股列表                 │
│  - 日线历史数据 (5年)               │
│  - 财务报表数据                     │
│  - 估值指标数据                     │
├─────────────────────────────────────┤
│  AKShare API (数据源)               │
│  - 首次加载完整数据                 │
│  - 每日增量更新                     │
└─────────────────────────────────────┘
```

**更新策略：**
- 启动时：加载股票池内所有股票的完整数据
- 每日 16:00：增量更新当日行情数据
- 每季度：更新财务报表数据
- 股票池变更时：加载新增股票数据
