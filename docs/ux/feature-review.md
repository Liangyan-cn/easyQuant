## 2. 因子模块 (Factors)

### 路由
- `/factors` - 因子列表
- `/factors/:id` - 因子详情

### 功能说明

#### 因子列表页
| 功能 | 说明 | 小白使用指南 |
|------|------|--------------|
| 因子列表 | 展示所有因子（名称、代码、分类、类型） | 查看已有因子 |
| 搜索筛选 | 按名称/代码搜索，按分类筛选 | 快速找到目标因子 |
| 新建因子 | 创建自定义因子 | 填写名称、代码、分类、公式 |
| 编辑因子 | 修改自定义因子 | 仅自定义因子可编辑 |
| 删除因子 | 删除自定义因子 | 仅自定义因子可删除 |
| 初始化内置因子 | 一键创建系统预设因子 | 首次使用时点击 |

#### 因子详情页
| 功能 | 说明 | 小白使用指南 |
|------|------|--------------|
| 基本信息 | 展示因子详细信息 | 了解因子定义 |
| 因子分析 | 计算因子值并评估效果 | 选择日期范围 → 开始分析 |
| IC 时序图 | 展示因子预测能力随时间变化 | IC > 0.03 表示有效 |
| 分组收益图 | 展示因子分组的收益差异 | 单调递增/递减表示有效 |

### 核心概念解释
- **因子**: 用于预测股票收益的量化指标（如 PE、ROE、动量等）
- **IC (信息系数)**: 因子值与未来收益的相关性，越高越好
- **IR (信息比率)**: IC 均值 / IC 标准差，衡量因子稳定性

### 用户操作流程
1. 查看因子列表 → 搜索/筛选
2. 点击"初始化内置因子"创建预设因子（首次使用）
3. 点击"新建"创建自定义因子
4. 点击"详情"进入因子详情
5. 选择日期范围 → 开始分析 → 查看结果

## 3. 策略模块 (Strategies)

### 路由
- `/strategies` - 策略列表
- `/strategies/:id` - 策略详情

### 功能说明

#### 策略列表页
| 功能 | 说明 | 小白使用指南 |
|------|------|--------------|
| 策略列表 | 展示所有策略 | 查看已有策略 |
| 搜索筛选 | 按名称/代码搜索，按类型/状态筛选 | 快速找到目标策略 |
| 新建策略 | 创建自定义策略 | 填写名称、代码、类型、逻辑 |
| 复制策略 | 克隆现有策略 | 基于现有策略修改 |
| 编辑/删除 | 管理自定义策略 | 仅自定义策略可操作 |

#### 策略详情页
| 功能 | 说明 | 小白使用指南 |
|------|------|--------------|
| 基本信息 | 展示策略详细信息 | 了解策略逻辑 |
| 运行回测 | 创建并执行回测 | 配置参数 → 创建回测 → 执行 |
| 回测历史 | 查看历史回测记录 | 对比不同参数效果 |
| 回测结果 | 展示绩效指标和权益曲线 | 评估策略效果 |

### 核心概念解释
- **策略**: 定义买卖规则的交易逻辑
- **回测**: 用历史数据验证策略效果
- **夏普比率**: 风险调整后收益，> 1 表示较好
- **最大回撤**: 最大亏损幅度，越小越好

### 用户操作流程
1. 查看策略列表 → 使用内置策略或新建
2. 点击"详情"进入策略详情
3. 点击"运行回测" → 配置参数
4. 创建回测 → 执行回测
5. 查看回测结果和权益曲线

## 4. 沙盒模块 (Sandbox)

### 路由
- `/sandbox` - 沙盒账户列表
- `/sandbox/:id` - 沙盒账户详情

### 功能说明

#### 沙盒账户列表页
| 功能 | 说明 | 小白使用指南 |
|------|------|--------------|
| 账户列表 | 展示所有虚拟账户 | 查看账户资产状况 |
| 新建账户 | 创建虚拟交易账户 | 设置名称和初始资金 |
| 编辑/删除 | 管理账户 | 修改名称或删除账户 |

#### 沙盒账户详情页
| 功能 | 说明 | 小白使用指南 |
|------|------|--------------|
| 账户概览 | 展示资产统计 | 查看总资产、收益率 |
| 持仓管理 | 查看当前持仓 | 了解持有股票和盈亏 |
| 交易记录 | 查看历史交易 | 追踪交易历史 |
| 策略部署 | 部署策略到账户 | 选择策略 → 配置 → 部署 |
| 入金 | 添加资金 | 增加可用资金 |
| 重置账户 | 清空数据重新开始 | 重置所有持仓和交易 |

### 核心概念解释
- **沙盒账户**: 虚拟交易账户，用于模拟真实交易
- **策略部署**: 将策略应用到账户，自动执行交易
- **净值**: 账户总资产价值

### 用户操作流程
1. 新建沙盒账户 → 设置初始资金
2. 进入账户详情 → 部署策略
3. 选择策略 → 配置参数 → 创建部署
4. 运行策略 → 查看持仓和交易
5. 对比多个策略的绩效

## 5. 数据模块 (Stocks)

### 路由
- `/stocks` - 股票列表/股票池
- `/stocks/:code` - 股票详情

### 功能说明

#### 股票列表页
| 功能 | 说明 | 小白使用指南 |
|------|------|--------------|
| 股票列表 | 展示 A 股列表 | 查看股票基本信息 |
| 搜索筛选 | 按名称/代码搜索，按市场筛选 | 快速找到目标股票 |
| 股票池管理 | 管理自定义股票池 | 创建/编辑股票池 |

#### 股票详情页
| 功能 | 说明 | 小白使用指南 |
|------|------|--------------|
| 实时行情 | 展示股票最新价格 | 查看当前价格和涨跌 |
| K线图 | 展示历史价格走势 | 切换日/周/月线查看 |

### 核心概念解释
- **股票池**: 一组股票的集合，用于回测和交易
- **K线图**: 展示开盘价、收盘价、最高价、最低价
- **成交量**: 交易的股票数量

### 用户操作流程
1. 查看股票列表 → 搜索目标股票
2. 点击股票进入详情 → 查看行情和 K 线
3. 切换到股票池 Tab → 管理股票池
4. 创建股票池 → 添加股票
