## 优先级排序

### 🔴 阻塞问题 (必须修复)

1. **H1** - 首页卡片点击无反应
2. **D2** - 股票池股票列表无法跳转详情
3. **D3** - 股票池详情缺少搜索功能
4. **G1** - /settings 页面白屏
5. **G2** - /profile 页面白屏

### 🟡 困惑问题 (需要解释)

1. **F1** - 初始化内置因子功能不明确
2. **F2** - 内置因子缺少说明
3. **S1** - 策略状态流转不清楚
4. **S2** - 内置策略缺少说明
5. **H2** - 首页设计原则不明确

### 🟢 建议改进 (提升体验)

1. **D1** - 股票池 Tab 顺序调整
2. **D4** - 股票选择组件优化
3. **D5** - 股票列表添加股票池筛选
4. **S3** - 多策略对比回测
5. **H3** - 未实现功能标识
